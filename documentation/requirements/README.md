# Requirements

Put system requirements in [system.md](system.md). Put subsystem requirements in `<subsystem>.md`, such as [integration.md](integration.md). Put verification beside its requirements as `<subsystem>-verification.md` or `system-verification.md`. The system ConOps can be `system-conops.md` here.

For a new requirement, use [integration.md](integration.md) as the template: give it an ID, state its parent system requirement, and say how it will be checked by test, analysis, inspection, or demonstration. Use `INT`, `IE`, `CI`, or `SS` for the respective subsystem's IDs.
