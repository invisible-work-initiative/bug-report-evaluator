# Integration

Andy and Meshaal. Slack: `#bugs26-integrators`.

Put this subsystem's documents in this folder:

- [working-agreement.md](working-agreement.md)
- `requirements.md`
- `verification.md`

In `requirements.md`, number them `INT-1`, `INT-2`, and point each one at the system requirement it comes from (`R1`, `R2`, …). Say how you will check it: test, analysis, inspection, or demonstration.

Interface agreements are shared. They go in [interfaces](../../interfaces/), and both subsystems approve them. Integration keeps an eye on which ones are missing.
